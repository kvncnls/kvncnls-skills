# About Focal

Focal is a product-judgement Skill for deciding what belongs inside a functional screen, what waits, and what deserves attention.

Its north star is **One Screen, One Clear Intent**. That means one legible organizing reason, not one universal action. A task screen usually has one primary action; a hub can offer many ranked routes; an exploration surface can foreground many items. Focal classifies the screen before judging it.

Three disciplines support the method:

1. **Information Architecture**—what belongs and how it is grouped.
2. **Progressive Disclosure**—what appears now, on demand, or never. A small number of decision chunks is a diagnostic starting point, not a universal item limit.
3. **Visual Hierarchy**—what wins attention and whether that order matches the action model.

Focal can build a Screen Spec or audit an existing surface. Audits score the three disciplines `0–4` for a native `/12`, explain every score from evidence, and return up to three warranted top moves with exact Screen · Flow · State · Lifecycle locators. A `3/4` is strong professional work; a `4/4` is above-and-beyond and intentionally uncommon.

Focal owns screen structure and attention. Compass owns the journey, Flywheel the relationship, and Soul authored memory. It does not implement layout, typography, color, motion, or code.
